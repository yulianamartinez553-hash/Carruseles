CARRUSEL STLABS — POST NO ERA PARA BUSCAR (RFC 10008 / QUERY)
==============================================================

Clon del carrusel de referencia (12 slides) con identidad STLabs, modo BLANCO
(pedido explícito). Robots pixel-art recreados como SVG:
  - POST  → naranja idéntico a la referencia (#FF5A2E), cejas enojadas, placa "POST".
  - QUERY → verde de marca (#00FFB2), anteojos negros, sonrisa, placa "QUERY".
  - GET   → azul (#2F7BFF), ojos tristes, placa "GET".

Contenido
---------
- slide-01..12.png   → PNGs retina 2160×2700 listos para Instagram.
- STLabs-QUERY-RFC10008.html → HTML standalone editable, fuentes embebidas en base64.
- _preview-tira.png  → tira de preview.
- STLabs-QUERY-RFC10008.zip  → PNGs + HTML.
- src/               → generate.py, robots.py, qa.py, pack.py (reproducir: python3 src/generate.py
                       con el repo en sys.path, luego render + pack).
